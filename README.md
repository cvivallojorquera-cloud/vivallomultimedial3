<h3 style="color: blue;">Portafolio de artista visual</h3>

Sitio web sobre mi trabajo artístico y lo que significa para mí lo multimedial. Durante el curso fui ajustando el fondo y la organización de las páginas. Luego adapté el sitio para presentarlo como portafolio de mi cuenta de arte en Instagram.

[🌐 Abrir el sitio web](https://cvivallojorquera-cloud.github.io/vivallomultimedial3/)

<h2 style="color: blue;">Archivos del sitio</h2>

<h3 style="color: blue;"><code>index.html</code> — Inicio</h3>
1. Presenta el portafolio y el nombre de artista.
2. Usa un fondo, un marco y efectos visuales.
3. Enlaza las secciones Obra, Galería y Contacto.

<h3 style="color: blue;"><code>p1.html</code> — Obra / Statement</h3>
1. Presenta un texto sobre los temas e ideas de mi trabajo artístico.
2. Incluye un enlace para volver al inicio.

<h3 style="color: blue;"><code>p2.html</code> — Galería</h3>
1. Organiza las obras en tres páginas.
2. Permite navegar entre las páginas y ampliar las imágenes.
3. Muestra información de cada obra al seleccionarla.
4. Las imágenes de las obras son propias.

<h3 style="color: blue;"><code>p3.html</code> — Contacto</h3>
1. Presenta una imagen en la sección de contacto.
2. Incluye un enlace a Instagram y otro para volver al inicio.
